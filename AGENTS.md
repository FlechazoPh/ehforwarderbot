## Agent skills

### Redeploy on a fresh server

To deploy this stack on a new machine, follow `docs/agents/redeploy.md` (architecture,
required secrets, step-by-step commands, verification and troubleshooting).

### Issue tracker

Issues and specs live as Markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

The repository uses a multi-context layout with a root `CONTEXT-MAP.md`, system-wide ADRs, and context-specific documentation. See `docs/agents/domain.md`.
